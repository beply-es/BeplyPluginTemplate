# BeplyPluginTemplate

## Respuesta rapida

BeplyPluginTemplate es la plantilla base para crear plugins Beply de FacturaScripts con testing, documentacion, CI/CD y contrato de tools IA.

## Quien puede verlo o usarlo

Equipo tecnico Beply y agentes IA que creen nuevos plugins.

## Donde esta

Repositorio del plugin y flujo de release de GitHub Actions.

## Campos, botones o estados importantes

| Elemento | Donde aparece | Que hace | Test |
| --- | --- | --- | --- |
| Plugin en AdminPlugins | Administracion de plugins | Verifica que el plugin aparece instalado en runtime | `tests/e2e/smoke.spec.ts` |
