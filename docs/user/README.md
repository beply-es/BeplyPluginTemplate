# Documentacion de usuario

Esta carpeta contiene la documentacion local del plugin antes de sincronizarla con la documentacion general de Beply.

## Paginas

- `modulo.md`: pagina base del modulo.

## Reglas

- Escribir para usuarios finales.
- Documentar campos, botones, estados, permisos, errores y flujos.
- Enlazar paginas base afectadas mediante `docs/docs-sync/impact-map.json`.
- Mantener la documentacion al mismo nivel que la version publicada del plugin.
