# Politica de no acceso a codigo original

## Permitido

- Browser.
- Capturas.
- Inventarios funcionales.
- Tests visuales.

## Prohibido

- Codigo fuente del original.
- Assets del original.
- Base de datos del original.
- Plantillas, CSS o JS del original.

## Incidente

Si se ve codigo original por error, registrar el incidente y rehacer la parte afectada.
